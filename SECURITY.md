# Security

Please report a suspected vulnerability privately, through this repository's
**Security › Report a vulnerability** (GitHub private vulnerability
reporting), not in a public issue or pull request.

Useful to include: the plugin version (`mesh-llm plugins info
capsule-emit-mesh`), the mesh-llm version, what you did, what you expected,
and what happened. A record, log line or checkpoint that shows the problem
helps. Never include a node's private key.

In scope: the plugin (`crates/evidence-plugin`), the Evidence page
(`web-ui/`), the packaging and release workflow. Issues in mesh-llm itself go
to [Mesh-LLM/mesh-llm](https://github.com/Mesh-LLM/mesh-llm); issues in the
sealing crates go to their own repositories.
